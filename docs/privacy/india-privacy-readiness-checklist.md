# India Privacy Readiness Checklist

> Status: Loop 0 — pre-implementation checklist for DPDP-aligned engineering. **Not a compliance claim.**

## Governance

- [ ] Qualified Indian legal review of Data Fiduciary / Processor matrix
- [ ] Privacy notice, terms, AI notice — all marked DRAFT FOR LEGAL REVIEW
- [ ] Grievance officer appointed and published (founder action)
- [ ] Data Protection Board registration requirements assessed (legal)

## Notice & Consent

- [ ] Separate consents for core service, AI, marketing, analytics
- [ ] Notice versioning with recorded acceptance
- [ ] Withdrawal as easy as grant; limitations explained accurately
- [ ] External reviewer notice before personal data processing
- [ ] Plain language; mobile accessible; English first, i18n-ready

## Data Principal Rights

- [ ] Privacy centre: access, export, correction, erasure, grievance
- [ ] Never paywalled
- [ ] Identity verification workflow documented
- [ ] Response SLA configured and monitored
- [ ] Nominee workflow placeholder documented

## Minimisation

- [ ] No default collection of Aadhaar, PAN, biometrics, etc.
- [ ] Upload warnings for unnecessary sensitive documents
- [ ] IP/device data only with documented purpose and retention
- [ ] Logs exclude document content and secrets

## Retention & Deletion

- [ ] Purpose-based retention in configuration
- [ ] Orchestrated deletion across DB, blob, cache, AI outputs, exports
- [ ] Backup expiry accurately communicated
- [ ] Pre-deletion user notification where appropriate

## Cross-Border

- [ ] Subprocessor register maintained
- [ ] AI provider off by default until approved
- [ ] Transfer risk assessment for each cross-border processor
- [ ] India-region storage preference documented

## Children

- [ ] 18+ age declaration at registration
- [ ] Terms prohibit minor accounts
- [ ] No AI age inference from photos
- [ ] Child data incident workflow documented

## Security Alignment

- [ ] Tenant isolation tested
- [ ] Encryption at rest and in transit
- [ ] Incident response plan linked
- [ ] Breach notification process (legal review)

## Launch Gate

Do not claim DPDP compliance publicly until legal sign-off on notices, roles, and operational procedures.
